# Joshua Nuru — Personal Portfolio

## Project overview

Joshua Nuru's responsive, editorial-style portfolio for software engineering, mathematics, data, and product work.

## Pages

- `index.html` — primary one-page portfolio experience
- `about.html` — background, education, focus, and toolkit
- `resume.html` — education, experience, and core skills
- `portfolio.html` — selected work and project summaries
- `portfolio-details.html` — featured case study
- `services.html` — capabilities
- `service-details.html` — working approach
- `contact.html` — contact details and Formspree form
- `thank-you.html` — form success state

## Technologies

- HTML5, CSS3, and vanilla JavaScript
- DM Sans, IBM Plex Mono, and Instrument Serif via Google Fonts
- Formspree for the contact form
- Existing project imagery and live project links
